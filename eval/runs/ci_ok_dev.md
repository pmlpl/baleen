# G1/G2 判定指标 bootstrap 置信区间(split=dev，ok 口径（剔除 G0）)

数据:labels.csv(人工金标准)× preds.csv(线 J 预测)的配对样本。

方法:**比例类指标(误拒率/误丢率/话题召回率/判定准确率/Recall@k)用 Clopper-Pearson 精确区间**(二项分布反解,95% 双侧)——零事件与全事件都有意义;macro-F1 / MRR 这类连续指标用 B=2000 次有放回重采样,seed=42 可复现,95% 百分位区间。

⚠️ 为什么比例指标不用 bootstrap:**零事件时百分位法会报 `[0%, 0%]`**(0/47 重采样几乎每次都是 0 次事件,分位点全落端点),等于宣称「真实率必然是 0」——那是不成立的。CP 精确法给出 [0%, 7.5%],才是诚实口径。

| 指标 | 点估计 | 95% 置信区间 | n | 区间方法 |
|---|---|---|---|---|
| 误拒率(越低越好) | 0.0% | [0.0%, 11.6%] | 30 | CP 精确 |
| 误丢率(越低越好) | N/A（无该类样本） | N/A | 0 | — |
| 话题召回率 | N/A（无该类样本） | N/A | 0 | — |
| 判定准确率 | 97.1% | [85.1%, 99.9%] | 35 | CP 精确 |
| macro-F1 | 66.1% | [64.7%, 100.0%] | 2000 | bootstrap |
