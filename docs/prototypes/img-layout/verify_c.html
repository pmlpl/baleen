1.1 国债的定义与由来

国债是国家以其信用为基础，按照债券的一般原则，通过向社会筹集资金所形成的债权债务关系。政府发行国债的目的是为了筹集财政资金，用于弥补财政赤字、建设基础设施、应对突发事件等。

从历史看，国债最早出现在中世纪的意大利，当时城邦国家为了战争融资而向商人借款。现代国债体系则形成于 17 世纪的英国，英格兰银行成立后开始系统发行政府债券。

国债按期限可分为短期（1 年以内）、中期（1~10 年）和长期（10 年以上）。按发行主体可分为中央国债和地方政府债。按付息方式可分为附息国债和贴现国债。
